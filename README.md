# 🌟 About Emberlane

Emberlane is a community-driven platform where people can discover new hobbies, connect with individuals who share similar interests, and join communities built around what they love.

Whether you're into photography, coding, music, fitness, art, gaming, or any niche passion, Emberlane makes it easy to find your tribe and grow together.

# ✨ Features

- 🎯 Personalized hobby discovery
- 👥 Connect with people sharing similar interests
- 🏘️ Hobby-based communities

# 🚀 Getting Started

## Clone the repository

```bash
git clone https://github.com/Swapnil-Biswas/emberlane.git

cd emberlane
```

## Install dependencies

```bash
npm install
```

## Configure environment variables

Create a `.env` file.

```env
DATABASE_URL=
AUTH_SECRET=
NEXT_PUBLIC_APP_URL=
```

## Run the development server

```bash
npm run dev
```

Visit:

```
http://localhost:3000
```
